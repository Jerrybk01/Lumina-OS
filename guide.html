BUKA PHOTO PRO user guide

A local photo editor you run from a Desktop icon. Nothing is uploaded. Close the tray icon when you are finished.

1. Start the app

  1. Unzip the folder if you received a zip. Do not open files from inside the zip.
  2. Double-click BUKA PHOTO PRO on the Desktop, or start.bat in the folder.
  3. Your browser opens the editor. A tray icon appears near the clock.
  4. To quit, right-click that tray icon and choose Quit.

If the browser does not open, right-click the tray icon and choose Open BUKA PHOTO PRO. If a copy is already running, a second click just reopens the window.

2. Open a photo

  • Open image / RAW — JPEG, PNG, WebP, and most camera files.
  • Tools → File → Open RAW preview… — uses the JPEG preview inside a RAW file (not a full develop).
  • Live camera — stills and video. Needs this local app (not a file:// page).
  • Drag a photo onto the window. Drag a .buka.json file to reopen a project.

Large photos open at up to 4096 px on the long edge so the tab stays responsive. Use Image Size… if you need a different working size.

3. Edit

  • Adjust panel on the right — exposure, color, contrast, and more.
  • Left rail — Erase, Compose, Text, Cutout, Studio, A/B, Mask, Graph, Projects, New.
  • Looks — presets sit beside the rail. Close with ×; reopen with the Looks chip or Tools → View → Looks panel.
  • Intent bar at the bottom (or Ctrl+L) — type what you want, e.g. “golden hour sky” or “erase object”.
  • Zoom — wheel, +/− in the top bar, or Space+drag to pan.
  • Crop — Crop button, then Apply.
  • Text — adds a responsive text box on the photo. Type, drag, and resize; words wrap and the type scales with the box.

4. Erase objects

Press E. Paint, box, or magic-select what should disappear, then Erase & fill. The hole is rebuilt from nearby texture (walls, sky, pavement work best). Undo with Ctrl+Z.

5. Background and studio

  • Transparent — subject on a checker. Export as PNG to keep the hole.
  • Compose — color, gradient, blur, or a new background image. First use may download a cutout model (~26 MB portrait or ~115 MB any subject).
  • Studio — subject on a cove with a shadow that follows the Light sun.

6. Live camera

Allow the camera when asked. + / −, the mouse wheel, or pinch zoom the live view. Drag to pan when zoomed. Capture sends the frame into the editor. Record (or R) makes a clip; stop, then save the video or grab a frame.

7. Resize and export

  • Tools → Image → Image Size… — change the working pixels.
  • Export… — pick a size, then PNG or JPEG. Transparent cutouts stay PNG.
  • File → Print… — prints only the picture, not the dark chrome.

8. Save your work

  • Save (Ctrl+S) — writes a .buka.json project file (and a recent copy in the browser).
  • Save Project As… (Ctrl+Shift+S) — choose a new file.
  • Open Project File… or Recent Projects… to continue later.

Sidecar on means “also write a small JSON of edit settings” when you export PNG + sidecar. It is not camera EXIF.

Keyboard shortcuts

  • Ctrl+L — Intent
  • Ctrl+Z — Undo · Ctrl+Y — Redo
  • Ctrl+S — Save project · Ctrl+Shift+S — Save As
  • E — Erase · M — Mask paint · G — Thought Graph · C — A/B
  • Alt (hold) — Scenescape tilt
  • In camera: R record · +/− zoom · 0 reset zoom · Esc close

What this software does not do

  • RAW files use the embedded preview, not a full demosaic develop.
  • Erase copies existing texture; it cannot invent a missing face or readable text.
  • Depth / “reconstruction” is an estimate for lighting looks, not a 3D scan.
  • Heal / soften items in the menu are blur mixes, not a Photoshop healing brush. Use Erase to remove objects.

If something goes wrong

  • Camera denied — use the lock icon in the address bar and allow the camera. The address must start with http://127.0.0.1.
  • Page will not load — look for the tray icon and Open, or run start.bat again.
  • Two copies — a second launch reopens the same editor. Quit from the tray first if you need a clean restart.
  • Cutout looks rough — wait for the model download, or pick Portrait vs Any subject in Compose.
